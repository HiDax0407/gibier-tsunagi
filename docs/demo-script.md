# デモ動画の台本（3分）「ある朝、わなに入った」

1人・1場面・前後で見せる。機能は場面の中で出てくる順にだけ見せる。
人名・地名・数はすべて架空のデモ（冒頭の被害額だけは農林水産省の公表値）。

## 人と場面

- **岩田さん**（架空・78歳）：北沢地区で見回り・処理・出荷・店の連絡を一人で抱える
- **高木さん**（架空・29歳・地域おこし協力隊）：ひと月前に募集カードの「記録」に手を挙げた。狩猟の資格はまだ
- **場面**：朝、わなに入った知らせ。そこから夕方までの一日。わなの地図は主役ではなく、物語の引き金

## 撮影の準備

1. アプリを開き、`#/asa` を開いて、確かめの画面で「OK」を押す（例：`http://localhost:8791/#/asa`）。
   チームの画面の下の「撮影用：『ある朝』の最初の状態にする」でも同じ
2. これで次の状態になる（この端末で足したものは消える）
   - 高木さんは、まだ「記録」に手を挙げていない
   - わなの知らせはまだない
   - 今朝の記録はない
   - 岩田さんの話は、まだ残っていない（チームの表の「本人の言葉で残った工程」は 0/7）
3. 撮り直すときは、もう一度 `#/asa` を開く
4. 端末はスマホの幅（375px 前後）。字は「大きな字」を押さない（表が画面に収まるように）

### 話す言葉（1:05 の見本）

この言葉で話すと、手順3つ・注意2つに分かれ、「冷やすのは、どのくらいの早さで？」と聞き返す。

> 朝はまず、わなの見回り。かかっとったら、仲間を呼んで二人以上で行く。一人で行くと危ない。止めたら、とにかく早う冷やして運ぶ。時間がたつと肉がダメになる。

答える言葉：

> 一時間のうちには冷やし始める。夏はもっと早う。

※ 声の入力はブラウザの音声入力。うまく拾えないときは「文字で入れる」に同じ言葉を入れる。
※ 「冷やす」「運ぶ」など話の中身は、デモ用の言葉。処理のやり方として正しいかを、このアプリは答えない。

- 「言葉が残った工程」は、話す画面で残した話にその工程の言葉が出てきたかで数える（今は言葉の照らし合わせ）
- 2/7 は上の「話す言葉」で話したときの数。違う言葉で話すと変わる
- 表の高さは朝と夕方で同じ（記録の行まで同じ位置に入る）。表の頭（「ベテランの経験が…」の線）を画面の上に合わせて撮ると、前後がそろう

## 字幕の注意

- Claude が働く瞬間だけ、字幕を1行「役：モデル（型）」で出す。説明の場面は作らない
- Claude につなぐ前に撮るときは、画面の端の印が「整理：見本（未接続）」「聞き返し：見本（未接続）」になっている。字幕もそれに合わせる
  - 例：「整理：見本（Claude 接続後は Opus 5.5）」「聞き返し：聞き方の型（Skill）・見本」
- 記録の抜けチェックはアプリの決まった照らし合わせで、AI は使っていない。サブエージェント（`.claude/agents/kiroku-nuke.md`）は、書き出した記録を読み直して「話した言葉と欄の食い違い」を足す役。字幕で「抜け探し：サブエージェント」と書くなら、リポジトリの場面（2:53）で見せる

## 守ること（動画・画面・README 共通）

- 数字は冒頭の188億円だけ。それ以外の数は「架空のデモ」と字幕で断る。「○件→○件に減った」のような効果の数は出さない
- 「資格が短くなる」とは言わない。短くなるのは「何から始めるか迷う時間」と「待つだけの時間」
- 見回りの決まりは県ごと。「チームと県に確認」を画面と字幕で。AI は法令・衛生・やり方を答えない
- 処理の場面は映さない。写真は後ろ姿・手元・食卓の3枚だけ
